# z translate

`z translate` 是一个基于 Manifest V3 的浏览器划词翻译扩展。选中文本后可以直接翻译，适合查英文网页、对照术语、临时记词和快速朗读。

当前仓库对应版本：`v1.2.2`（2026-07-09）

## 功能特点

- 划词即译：选中网页文字后可自动弹出翻译结果，也支持仅用快捷键触发。
- 快捷键操作：默认 `Alt+T` 翻译、`Alt+J` 加入词袋、`Alt+Shift+J` 清空词袋、`Alt+Shift+T` 快速翻译。
- 词袋模式：可连续收集多个词，再统一翻译，并自动判断是否构成词组。
- Ctrl+点击翻译：按住 `Ctrl` 点击网页上的链接或按钮，也能直接翻译其文字。
- 可用性优化：浮窗支持拖拽、缩放、固定、复制结果、历史记录查看和原文/译文朗读。
- 智能兜底：翻译后端支持按优先级自动降级，默认优先使用 `MyMemory`。
- 术语表与缓存：支持自定义术语映射，重复翻译可直接走缓存。

## 支持环境

- Chrome
- Edge
- Brave
- Opera
- 其他 Chromium 内核浏览器

## 安装方法

本项目是原生浏览器扩展源码，不需要构建。

### 方法一：双击脚本

- Chrome：运行 `install.bat`
- Edge：运行 `install-edge.bat`

### 方法二：手动加载

1. 打开浏览器扩展管理页，如 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前项目根目录
5. 安装完成后即可使用

## 使用说明

- 选中网页文字后按 `Alt+T` 触发翻译
- 选中单词后按 `Alt+J` 加入词袋
- 词袋有内容时再次按 `Alt+T`，可统一翻译整组词
- 按 `Alt+Shift+T` 可跳过语言检测，适合固定语言场景
- 所有快捷键都可以在 `chrome://extensions/shortcuts` 中自行修改

## 翻译后端说明

- `MyMemory`：默认首选，免费，无需 Key，国内可直连
- `Google`：可作为备用，但通常需要科学上网或额外网络配置
- `Youdao`：代码已保留，但当前版本仍标注为“待修复”

如果某个后端失败，扩展会按设置中的优先级自动尝试下一个后端。

## 项目结构

- `manifest.json`：扩展清单
- `src/background/`：后台 Service Worker
- `src/content/`：页面注入逻辑与翻译浮窗
- `src/options/`：设置页
- `src/lib/`：翻译调度、缓存、术语表、TTS、语言检测等公共逻辑

## 已知限制

- 当前仓库以“加载已解压扩展”的方式使用，没有打包上架流程。
- 有道后端暂未恢复到可直接使用状态。
- 历史记录保存在本地浏览器存储中，不会跨设备自动同步全部数据。
